# project
## Эта программа предназначена для поиска данных текстовых файлах
программа может найти следующие данные:
1. адреса электронной почты
2. номера банковских карт
3. ключевые слова
## Установка
1. Установить python
2. Клонировать репозиторий
## Запуск программы:
ввести команду: python app.py
## Запуск тестов:
команда: python -m unittest discover
