# File Scanner Web App

## Описание
Это веб-приложение на Flask для анализа загружаемых файлов.  
Система извлекает из текста файла:
- Email адреса
- Номера банковских карт (по шаблону)
- Ключевые слова (например: пароль, login, секретно и др.)

## Функциональность
- Загрузка текстового файла через веб-интерфейс
- Анализ содержимого через pipeline архитектуру
- Возврат структурированного результата
- Отображение результата на HTML странице
